# Robot Demonstration Video

This video demonstrates the developed Arduino-based mobile robot.

## Demonstrated Functions

- IR remote-controlled movement
- DC geared motor operation
- Ultrasonic distance measurement
- Servo-based ultrasonic sensor scanning
- Obstacle detection
- Obstacle avoidance
